## 👁️ The Grande

The sky shifts unnaturally. A rhythmic ticking echoes across the isolated landmass. 

It is coming. Once *The Grande* chooses you, time begins to collapse. The others are panicking. Some are watching. Some are running. 

Do not let the ticking stop while it is with you. 

Enter the arena.

### ✨ The Experience

- **🌐 The Network:** Instant, zero-lag synchronization. You won't know if you're running from a friend or something else.
- **🤖 The Entities:** They aren't just bots. They observe, they panic, and they react. Don't assume they'll just stand there. 
- **🎙️ Proximity Communications:** Talk to those around you in real-time. But remember, the system is always listening.
- **🛡️ The Overseer:** An automated moderation system ensures the arena remains clean. Toxicity is immediately punished.
- **🌅 Time Shifts:** The environment changes based on when you dare to enter. 
- **💎 The Interface:** A stunning, reactive glassmorphism terminal that watches your every move.

## 🛠️ Technology Stack

Built with modern, high-performance web technologies:

**Frontend (Client)**
* **React 18 & Vite** - Lightning-fast UI rendering
* **Three.js & React Three Fiber (R3F)** - Core 3D WebGL rendering engine
* **React Three Drei** - 3D helpers, camera controls, and environments
* **Tailwind CSS** - Rapid, beautiful UI styling

**Backend (Server)**
* **Node.js & Express** - Scalable server architecture
* **Socket.io** - Real-time bidirectional event-based communication
* **PeerJS (WebRTC)** - Low-latency peer-to-peer audio streaming

## 🚀 How to Run Locally

Want to test your survival skills locally? Follow these simple steps:

### 1. Start the Backend Server
```bash
cd backend
npm install
node index.js
```
*The server will start running on `http://localhost:3001`*

### 2. Start the Frontend Client
Open a new terminal window:
```bash
cd frontend
npm install
npm run dev
```
*The game will launch in your browser at `http://localhost:5173`*

## 🕹️ Controls

- **[W, A, S, D]** - Move freely around the island
- **[SPACE]** - Jump
- **[MOUSE]** - Look around (Roblox-style 3rd person camera)
- **[COLLIDE]** - Run into another player to pass the bomb!
