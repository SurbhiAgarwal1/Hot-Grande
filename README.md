## 🎮 About The Game

**Hot Grande** is an adrenaline-fueled 3D multiplayer survival game where players are trapped on an island with a ticking time bomb. One player starts with the bomb—if the timer hits zero while you hold it, you explode and are eliminated! 

Run, jump, and frantically pass the bomb to other players to survive. Last player standing wins!

### ✨ Key Features

- **🌐 Real-Time Multiplayer:** Instant, zero-lag synchronization using Socket.io. Play with friends or against our intelligent AI.
- **🤖 Advanced Psychological AI:** Bots aren't just mindless drones. They feature simulated human reaction times, panic modes, and advanced pathfinding to ensure they play exactly like real people.
- **🎙️ Proximity Voice Chat:** Talk to other players in real-time using WebRTC.
- **🛡️ AI Voice Moderation:** A strict, automated moderation system ensures the arena remains toxic-free.
- **🌅 Dynamic Environments:** A beautiful real-time Day/Night cycle that matches your local time.
- **💎 Premium UI/UX:** Stunning, modern glassmorphism interfaces, cinematic landing pages, and reactive mouse parallax effects.

## 🛠️ Technology Stack

Built with modern, high-performance web technologies:

**Frontend (Client)**
* **React 18 & Vite** - Lightning-fast UI rendering
* **Three.js & React Three Fiber (R3F)** - Core 3D WebGL rendering engine
* **React Three Drei** - 3D helpers, camera controls, and environments
* **Tailwind CSS** - Rapid, beautiful UI styling

**Backend (Server)**
* **Node.js & Express** - Scalable server architecture
* **Socket.io** - Real-time bidirectional event-based communication
* **PeerJS (WebRTC)** - Low-latency peer-to-peer audio streaming

## 🚀 How to Run Locally

Want to test your survival skills locally? Follow these simple steps:

### 1. Start the Backend Server
```bash
cd backend
npm install
node index.js
```
*The server will start running on `http://localhost:3001`*

### 2. Start the Frontend Client
Open a new terminal window:
```bash
cd frontend
npm install
npm run dev
```
*The game will launch in your browser at `http://localhost:5173`*

## 🕹️ Controls

- **[W, A, S, D]** - Move freely around the island
- **[SPACE]** - Jump
- **[MOUSE]** - Look around (Roblox-style 3rd person camera)
- **[COLLIDE]** - Run into another player to pass the bomb!
